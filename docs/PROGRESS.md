- 제외: 지출, 세액 계산, 데이터 가져오기, 부가 정보, 데이터 공유
- 세금: 연간 총액 요약만 / 비용: 무료 티어만
- 일정: **1개월 안 실사용** (M3 2026-12-26)
- 목적: 실사용 + 학습/포트폴리오
