# 용어집 (Glossary)

> 상태: 초안 · 최종 수정일: 2026-11-27
> 코드의 이름(영문)과 도메인 용어(한글)를 일치시키기 위한 문서. 새 용어는 여기에 먼저 추가한다.
> "확인 필요" 표시는 사용자 확인 전 추정치.

| 한글 용어 | 영문(코드명) | 정의 | 확인 |
|---|---|---|---|
| 캐디하루 | CaddyHaru (`caddy-haru`) | 이 앱의 이름. 표기 규칙은 `project-charter.md` §0 | ✅ |
| 캐디 | Caddy | 골프 라운드에서 경기 보조를 하는 근무자. 앱의 사용자 | ✅ |
| 사용자 | User | 앱에 가입한 캐디 1명. 데이터는 사용자별로 분리된다 | ✅ (Q-001) |
| 라운드 | Round | 캐디 1회 근무 단위 (기본 18홀). 하루에 여러 번 있을 수 있다 | ✅ (Q-003, Q-015) |
| 나인추가 | NineHoleExtension | 1부 18홀 뒤에 고객 요청으로 9홀을 더 도는 것. 1회당 캐디피의 절반을 더 받으며, 한 라운드에 여러 번 가능 | ✅ (Q-021~Q-023) |
| 나인추가 횟수 | nineExtensionCount | 한 라운드의 나인추가 횟수 (정수) | ✅ |
| 나인추가 금액 | NineExtensionFee | 나인추가로 받은 금액. 기본값 = 캐디피 ÷ 2 × 횟수, 수정 가능 | ✅ (Q-021) |
| 환산 라운드 수 | RoundEquivalent | 통계용 라운드 수. 라운드 1건 = 1 + 0.5 × 나인추가 횟수 | ✅ (Q-024) |
| 부 | RoundSlot | 하루 중 라운드 순서 구분: 1부 / 2부 / 3부 | ✅ (Q-014) |
| 기본 캐디피 | DefaultCaddyFee | 골프장마다 저장해 두는 캐디피 기본값. 라운드 입력 시 자동으로 채워진다 | ✅ (Q-012) |
| 기본 골프장 | DefaultGolfClub | 라운드 입력 시 처음 선택돼 있는 골프장 | ✅ |
| 카카오 로그인 | KakaoLogin | 앱의 유일한 로그인 수단 | ✅ (Q-011) |
| 캐디피 | CaddyFee | 라운드 1회에 대해 받는 기본 보수 | ✅ (Q-002) |
| 오버피 | OverFee | 기본 캐디피 외에 고객에게 추가로 받는 금액 | ✅ (Q-002) |
| 라운드 수입 | RoundIncome | 캐디피 + 나인추가 금액 + 오버피 | ✅ |
| 골프장 | GolfClub | 근무지. 사용자마다 따로 등록하며 여러 곳일 수 있다 | ✅ (Q-A01) |
| 연간 요약 | AnnualSummary | 1년간 총수입·라운드 수. 종합소득세 신고 참고용 | ✅ (Q-005) |

## 사용하지 않기로 한 용어
| 용어 | 이유 |
|---|---|
| 대기료/취소료 | 수입 항목에 없음 (Q-002) |
| 지출 | 지출 기록은 범위 밖 (Q-004) |
| 결제수단(현금/계좌) | 구분 불필요 (Q-008) |
| 9홀 단독 라운드 / 홀 수 | 9홀만 도는 라운드는 없음. 9홀은 "나인추가"로만 다룬다 (Q-015) |
| 팀 인원, 티오프 시간, 코스명, 메모 | 라운드 부가 정보 기록 안 함 (Q-013) |
