## 1. 배경 / 문제 정의
- 캐디는 라운드마다 캐디피와 오버피를 받고, 하루에 여러 라운드를 나가는 날도 있어서 수입이 날마다 다르다.
- 수입이 여기저기 흩어져 기록되기 때문에 월 수입을 파악하거나 종합소득세 신고(5월) 때 1년 총액을 정리하기 어렵다.
- 현재는 일반 가계부 앱이나 휴대폰 메모에 기록한다 (Q-A03). 일반 가계부 앱에는 라운드·부·골프장별 캐디피 같은 캐디 업무 개념이 없고, 메모는 합계를 내기 어렵다.

## 2. 목적 (Goals)
이 프로젝트는 **실사용**과 **학습/포트폴리오** 두 가지를 함께 노린다. (Q-A02)

| ID | 목표 | 측정 방법 |
|---|---|---|
| G-1 | 라운드 1건을 휴대폰으로 30초 안에 기록할 수 있다 | 입력 화면 사용성 테스트 (NFR-001) |
| G-2 | 월 수입을 한눈에 확인할 수 있다 | 월 통계 화면 제공 (FR-011) |
| G-3 | 종합소득세 신고 때 참고할 연간 총수입을 바로 확인할 수 있다 | 연간 요약 (FR-030) |
| G-4 | 지인 캐디 몇 명이 각자 계정으로 실제 사용한다 | 실사용자 수, 한 달 이상 사용 |
| G-5 | 요구사항 → 설계 → 구현 → 테스트를 추적할 수 있는 문서 체계를 갖춘다 (포트폴리오) | 추적성 매트릭스 완성 |

## 3. 범위 (Scope)
### 포함 (In Scope)
- 계정: 카카오 로그인, 사용자별 데이터 완전 분리
- 라운드 기록: 날짜, 부(1부/2부/3부), 골프장, 캐디피, 오버피, 나인추가(1부만) — 하루 여러 라운드 가능
- 골프장 관리: 사용자별 골프장 목록, 골프장별 기본 캐디피, 기본 골프장
- 조회/통계: 달력, 월별 통계, 연간 추이
- 연간 총액 요약, CSV 내보내기

### 제외 (Out of Scope)
- 지출 기록 (Q-004)
- 예상 세액 계산, 실제 세금 신고 대행, 홈택스 연동 (Q-005)
- 기존 엑셀/메모 데이터 가져오기 (Q-009)
- 오프라인 입력 (Q-007)
- 현금/계좌 등 결제수단 구분 (Q-008)
- 라운드 부가 정보(팀 인원, 티오프 시간, 코스명, 메모) (Q-013), 9홀 단독 라운드 (Q-015)
- 사용자 간 데이터 공유·통계 비교 (Q-016)
- 카카오 외 로그인 수단 (Q-011)
- 골프장 측 캐디 배정·관리 기능

## 4. 이해관계자 / 대상 사용자
| 구분 | 설명 |
|---|---|
| 주 사용자 | 지인 캐디 몇 명. 각자 다른 골프장에서 일하고 골프장을 옮기기도 한다 (Q-001, Q-A01) |
| 사용 환경 | 주로 휴대폰, 퇴근 후 집에서 기록 (Q-006, Q-007) |
| 개발/운영 | 사용자 본인 + Claude |

## 5. 제약 사항
- 비용: 운영비 0원. 무료 티어 서비스만 사용한다 (Q-010, NFR-007)
- 개인정보: 수입 정보는 민감하므로 본인만 볼 수 있어야 한다 (NFR-003)
- 일정: 1개월 안에 실사용 시작 (Q-A04) → MVP 범위는 Must 요구사항으로 한정하고, Should/Could는 그 이후에 한다
- 외부 의존: 카카오 로그인을 쓰려면 사용자가 카카오 개발자 콘솔에서 앱을 직접 등록해야 한다

## 6. 성공 기준
- MVP로 사용자 본인과 지인 캐디가 한 달 동안 실제 수입을 기록하고 월 통계를 확인한다.
- 문서(요구사항·설계·ADR·테스트)가 코드와 ID로 연결돼 있어 포트폴리오로 설명할 수 있다.
