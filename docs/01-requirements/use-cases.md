## UC-01 라운드 기록하기
| 항목 | 내용 |
|---|---|
| 액터 | 캐디 |
| 사전 조건 | 로그인한 상태, 골프장이 1개 이상 등록돼 있음 |
| 트리거 | 근무를 마치고 집에서 그날 수입을 기록하려 함 |
| 사후 조건 | 라운드가 저장되고 해당 일/월 수입에 반영됨 |

**기본 흐름**
1. 사용자가 "라운드 추가" 버튼을 누른다.
2. 시스템이 오늘 날짜, 기본 골프장, 그 골프장의 기본 캐디피, 부(그날 기록이 없으면 1부, 있으면 다음 부)가 채워진 입력 폼을 보여준다.
3. 사용자가 오버피를 입력하고, 필요하면 다른 값을 수정한다.
4. 사용자가 저장을 누른다.
5. 시스템이 입력값을 검증하고 저장한 뒤 목록/달력에 반영한다.

**대안 흐름**
- 3a. 지난 날짜를 기록 → 날짜를 바꿔 입력
- 3b. 골프장을 바꿈 → 캐디피가 새 골프장의 기본 캐디피로 바뀐다 (FR-006)
- 3d. 1부에서 나인추가를 함 → 나인추가 횟수를 선택하면 나인추가 금액(캐디피 ÷ 2 × 횟수)이 채워지고, 필요하면 금액을 고친다 (FR-008)
- 3c. 같은 날 두 번째 라운드 → 저장 후 "같은 날 하나 더 추가"로 2부터 반복 (FR-005)
- 5c. 같은 날짜·같은 부에 이미 라운드가 있음 → 저장하지 않고 "이미 N부 기록이 있습니다" 안내 후 3으로 (Q-017)
- 5d. 그날 1·2·3부가 모두 있음 → 더 추가할 수 없다고 안내
- 5a. 필수값(날짜, 골프장, 캐디피) 누락 또는 금액이 0 미만 → 오류 메시지 표시 후 3으로

**예외 흐름**
- 5b. 네트워크 오류 → 저장 실패 메시지 표시, 입력값은 화면에 유지 (오프라인 저장은 하지 않음, NFR-008)
