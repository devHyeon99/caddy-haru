# ADR-0004: 로그인 상태 관리 — DB 세션 (httpOnly 쿠키에 불투명 토큰)

> 상태: 승인 · 날짜: 2026-11-27

## 배경 (Context)
카카오 OAuth로 본인 확인을 마친 뒤, 이후 요청에서 "이 사람이 누구인지"를 기억할 방법이 필요하다.
- **FR-040** 카카오 가입·로그인·로그아웃, **AC-040-3** 로그아웃 후 데이터 화면이 보이지 않아야 함
- **NFR-003** 데이터 분리: userId는 서버가 믿을 수 있는 출처에서만 나와야 함
- ADR-0002 규칙 4: Render 무료 서버는 언제든 재시작될 수 있음 → **서버 메모리에 상태 금지**
- ADR-0002 규칙 1: httpOnly 쿠키, 같은 도메인(`/api/*` 프록시)
- 사용자 조건: 백엔드가 처음이고, **안정성과 학습 가치**를 중시. 일정은 1개월

## 선택지 (Options)
| 선택지 | 쿠키에 담는 것 | 장점 | 단점 |
|---|---|---|---|
| **① DB 세션** | 무작위 토큰(번호표). DB에 해시·user_id·만료 저장 | 로그아웃·강제 만료가 **즉시** 됨. 구현 단순. 토큰 탈취 시 피해 범위를 서버가 통제 | 요청마다 DB 조회 1번 (이 앱은 어차피 매 요청 DB 사용 → 실제 손해 거의 없음) |
| ② JWT 하나 (장기) | 서명된 `{userId, exp}` | DB 조회 없음. 서버 여러 대일 때 유리 | **발급한 토큰을 취소할 수 없음** → 로그아웃해도 탈취된 토큰은 만료일까지 유효 |
| ③ Access(15분 JWT) + Refresh(DB) | 둘 다 | 두 개념을 모두 배움. 면접 단골 주제 | 토큰 갱신, 동시 요청 중 갱신, refresh 교체 등 함정이 많음. 백엔드 첫 프로젝트·1개월 일정에 버그 위험 큼 |

## 결정 (Decision)
**① DB 세션을 채택한다.** (사용자 선택, 2026-11-27)

| 항목 | 값 |
|---|---|
| 토큰 | `crypto.randomBytes(32)` → base64url. 쿠키에만 존재 |
| DB 저장 | `sessions(token_hash = SHA-256(토큰), user_id, expires_at, created_at)` — 원본 토큰은 저장하지 않음 |
| 쿠키 | `__Host-sid`, `HttpOnly; Secure; SameSite=Lax; Path=/` |
| 수명 | 30일, 남은 기간이 15일 미만이면 요청 시 30일로 연장(슬라이딩) |
| 로그아웃 | DB 행 삭제 + 쿠키 `Max-Age=0` |
| 만료 정리 | 크론 없이, 로그인할 때 그 사용자의 만료 세션 삭제 |
| CSRF | SameSite=Lax + 상태 변경 요청의 `Origin` 검사. OAuth는 `state` 쿠키로 방어 |
| 카카오 access token | 회원번호 조회에만 쓰고 저장하지 않음 |

상세 시퀀스는 `docs/02-design/architecture.md` §4.

## 근거 / 결과 (Consequences)
**좋은 점**
- 서버 1대 + 요청마다 DB 사용인 구조에서는 JWT의 장점(DB 조회 생략)이 거의 의미가 없다. 반면 즉시 취소라는 세션의 장점은 그대로 얻는다.
- 구현할 부분이 적어서 1주차 목표("카카오 로그인 → API → DB 저장")를 지키기 쉽다.
- 쿠키 보안 속성, 토큰 해시 저장, 슬라이딩 만료, CSRF 방어를 직접 구현하며 배운다.
- Spring Security의 기본 방식(세션)과 개념이 같다.

**감수할 점**
- 요청마다 `sessions` 인덱스 조회가 1번 늘어난다 (수 ms).
- "JWT를 써봤다"는 경험은 이번에 얻지 못한다 → **이후 학습 과제**: Spring Boot 재구현(ADR-0002) 때 Access+Refresh JWT로 만들어 보고 두 방식을 비교하는 글을 포트폴리오에 남긴다.

**다시 검토할 조건**
- 서버를 여러 대로 늘리거나, 모바일 네이티브 앱이 생겨 쿠키를 쓰기 어려워질 때.

## 변경 이력
- 2026-11-27 작성·승인 (사용자 선택: ① DB 세션)
