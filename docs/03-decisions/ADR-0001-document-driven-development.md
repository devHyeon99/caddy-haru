# ADR-0001: 문서 주도 개발 방식과 문서 구조 채택

> 상태: 승인 · 날짜: 2026-11-26

## 배경 (Context)
사용자와 Claude가 여러 세션에 걸쳐 프로젝트를 진행한다. 세션은 이전 대화를 기억하지 못하므로,
맥락·결정·진행 상황이 파일로 남아 있지 않으면 매 세션마다 같은 논의를 반복하게 된다.

## 선택지 (Options)
| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 대화로만 진행 | 빠름 | 세션 간 맥락 유실, 결정 근거 없음 |
| B. 단일 문서에 모두 기록 | 단순 | 커지면 찾기 어렵고 세션이 다 읽기 부담 |
| C. SDLC 단계별 폴더 + CLAUDE.md + PROGRESS.md | 단계별 추적, 세션 진입점 명확 | 문서 갱신 습관 필요 |

## 결정 (Decision)
C를 채택한다.
- `CLAUDE.md`: 세션이 자동으로 읽는 규칙
- `docs/PROGRESS.md`: 세션 간 인수인계 지점
- 요구사항 ID(FR/NFR/UC/Q/ADR)로 문서와 코드를 연결

## 근거 / 결과 (Consequences)
- 좋은 점: 어떤 세션이든 CLAUDE.md → PROGRESS.md만 읽으면 이어서 작업 가능
- 감수할 점: 세션 종료 시 문서 갱신을 빠뜨리면 체계가 무너짐 → CLAUDE.md §5에 의무화
