# 세션 로그: 확정 후 요구사항 변경 — 나인추가

> 날짜: 2026-11-26 · 단계: Phase 2 진입 직후 (요구사항 변경)

## 배경
Must 요구사항 확정 직후 사용자가 빠진 도메인 규칙을 알려줌:
1부(18홀) 진행 중 고객이 원하면 9홀을 더 도는 "나인추가"가 있고, 캐디피의 절반을 더 받는다.
예: 캐디피 16만 + 나인추가 8만 = 24만 (+ 오버피는 있을 수도 없을 수도).
Q-015("9홀 없음")의 답이 불완전했던 것 → CLAUDE.md 원칙 6에 따라 사용자 요청으로 확정 요구사항 변경.

## 한 일
- 세부 규칙 인터뷰 Q-021~Q-024
- SRS: FR-008 신설, FR-001·007·011 수정, 공통 입력 규칙·인수 조건 추가 (AC-007-3, AC-008-1~9, AC-010-5, AC-011-5), AC-N005-2 수정
- 용어집·open-questions·유스케이스·헌장 반영

## 결정 사항
- 나인추가 금액 = 캐디피 ÷ 2 × 횟수 자동, 수정 가능 (Q-021)
- 1부만 가능 (Q-022), 여러 번 가능 → 횟수로 기록 (Q-023)
- 통계: 나인추가 따로 합계, 1회 = 0.5라운드 환산, 평균 = 총수입 ÷ 환산 라운드 수 (Q-024)

## 검토 필요한 가정 (⚠)
- 나인추가 최대 3회
- 캐디피가 홀수일 때 절반 금액은 원 단위 내림
- 나인추가 금액을 직접 고친 뒤에는 캐디피를 바꿔도 자동으로 다시 계산하지 않음

## 다음 세션에 넘길 것
- ⚠ 가정 승인 → 기술 스택 ADR-0002
- 데이터 모델에 반영: Round에 nineExtensionCount(정수), nineExtensionFee(정수), slot=1일 때만 count>0 제약

## 추가: 가정 확정 (같은 날)
- 나인추가 최대 3회 → **2회**로 수정 (AC-008-10 추가)
- 절반 금액 원 단위 내림, 직접 고친 금액 유지 → 승인
- SRS에 남은 ⚠ 없음 → FR-008 포함 Must 요구사항 전부 확정
