  - §4 와이어프레임: 깨우기 화면(1.5초 뒤부터 표시, 1분 뒤 추가 문구, 3분 뒤 실패와 [다시 시도], 오프라인), 사용 중 오버레이(깨어난 뒤 저장을 한 번만 보냄), 로그인과 `/login?error=cancelled|state|kakao` 문구, 홈, 라운드 추가(나인추가 자동·직접 입력·2/3부 비활성·부 변경 오류·필수 누락 상태), 수정(숨긴 골프장 표시), 삭제 확인 창 2개(골프장 `hidden`/`deleted` 토스트), 달력(7칸 × 46px)과 날짜 상세 시트, 통계(Should 연간 탭은 자리만), 설정·골프장 추가/수정.
  - §5 30초 흐름: **3탭 + 5키, 약 10초.** 오버피 0원이면 2탭. 다른 흐름(같은 날 2부, 나인추가, 다른 골프장, 지난 날짜)의 탭 수도 적었다.

## 결정 사항
(ADR로 남길 정도의 트레이드오프는 없어 ui-design에 적었다. 사용자 검토 대상이다.)
- 하단 탭 4개(홈·달력·통계·설정). 입력 화면은 탭 바 없이 [←]와 [저장]만 둔다.
- 저장 버튼은 **상단 바와 폼 하단 두 곳**에 둔다. 숫자 키패드에 완료 키가 없는 기기에서도 키보드를 닫지 않고 저장할 수 있게 하려는 것이다.
- 홈에서 C1과 D1(오늘)을 미리 불러와 폼을 서버 요청 없이 채운다.
- 오버피 칸을 누르면 `0`이 전체 선택된다. 탭 수는 iOS 기준 3탭으로 잡았다(자동 포커스는 기기마다 달라서).
- 나인추가가 있는 채로 2·3부로 바꾸면 횟수를 몰래 지우지 않고, 부 칸에 오류를 보여 저장을 막는다(AC-008-7과 같은 동작).
- 나인추가 금액을 직접 고치면 "직접 입력함"으로 표시하고 [자동 계산으로 되돌리기]를 둔다.
- 달력 칸은 만 원 단위로 축약하고 버림한다(`26만`). 정확한 금액은 날짜 상세와 월 합계에 표시한다.
- 첫 골프장은 "기본 골프장" 스위치가 켜진 채로 시작한다(AC-N001-3 전제를 쉽게 맞추려고).
- 라운드 삭제는 수정 화면에서만 할 수 있다(날짜 시트에서는 행을 누르면 수정 화면으로 간다). 로그아웃에는 확인 창을 두지 않는다.
- 사용 중 오버레이에서는 아직 보내지 않은 저장 요청을, 서버가 깨어난 뒤 한 번만 보낸다. 이미 보낸 요청은 자동으로 다시 보내지 않는다(architecture §5.3과 같음).
